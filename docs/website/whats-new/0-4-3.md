# What's new in 0.4.3

**Included in Free.** Product Roadmap has no paid version. No new permission.

- **Ideas fits the screen.** One long unbroken word in an idea, such as a pasted address, no longer makes the Ideas table wider than the window. Long words and long text are cut short with "…", and the title opens the idea's draft, where you can read all of it. See [Suggestions](../using/suggestions.md).
- **Each Decide menu names its idea.** The menu reads **Decide: (the idea's title)**, so screen readers can tell the rows apart, and the **Decision** column comes first, in view on a phone.
- **A decision keeps your page.** After **Approve** or **Reject** on page 3, Ideas shows page 3 again instead of the first page.
- **No Remove button that can only fail.** A stage that still has items shows no **Remove**. Its line says how many items to move first. See [Items and stages](../using/items-and-stages.md).
- **Merge progress where you started it.** After **Merge these two**, **Merge a duplicate** stays open with the next step and **Continue**. A small merge needs fewer presses, and you see "Merge finished." when it ends. See [Merge a duplicate](../using/merge-duplicates.md).
- **Readable vote counts when voting is off.** When a visitor cannot vote, the Vote buttons get a dashed edge instead of being faded, so the count stays easy to read.
- **Clearer Suggest form.** A blank title, or a guest's name made only of spaces, now says which field to fix and moves to it. Signed-in members are no longer asked for a name.
- **On Cloudflare, redeploy after installing or updating.** The registry install text now says so (emdash-cms/emdash#4865).

After you update, copy the site kit with tag `v0.4.3`. The board, the Suggest page, the wording file and the shared styles changed.
