# What's new in 0.2.1

**Included in Free.** Product Roadmap has no paid version.

- **Works next to WB Polls.** The My votes component is now `src/components/RoadmapVotes.astro`. Before, it had the same name as WB Polls' My votes, so copying one plugin's kit replaced the other's file. If your site has both plugins, copy both kits again.

Copy the site kit again after you update. You can delete an old `src/components/MyVotes.astro` only if your site does not use WB Polls.
