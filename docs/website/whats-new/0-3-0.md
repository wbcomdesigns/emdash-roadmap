# What's new in 0.3.0

**Included in Free.** Product Roadmap has no paid version.

**New permission:** Read retained content revision history, so the Stage panel can see and move an item while it has unpublished changes. You approve it once when you update.

- **Guests need a visitor address.** Guests can vote and suggest only when your host tells EmDash the visitor's address: Cloudflare does; any other host needs `trustedProxyHeaders` in the site config. Without it, guests see a sign-in link, members take part as usual, and Admin, Roadmap, Settings says so. See [Install](../getting-started/install.md#guests-and-the-visitor-address).
- **Fairer guest counting.** One guest per IPv4 address or per IPv6 /64. After 30 days a guest is forgotten on purpose: the salted address is cleared, the vote stays, and that guest may vote again.
- **One command for the kit.** `scripts/add-to-site.sh` copies every kit file, your layout only the first time, keeps a backup of a changed wording file, and creates the content types. Ideas shows the exact command for your version until you press **Visitor pages are set up**.
- **One place to set the stage.** The Stage panel on an item has a button per stage. An editor page opened before a move cannot undo it; a different stage typed in the Stage box is kept, and retyping a stage the panel just replaced is refused with a message. On an item with unpublished changes, the move goes into those changes. See [Items and stages](../using/items-and-stages.md).
- **Roadmap votes.** The member votes page and its menu label are now Roadmap votes, apart from WB Polls' My votes.
- **Fixes.** Ideas counts a waiting idea once; pages line up with your site's header; buttons stay readable in dark mode.

Copy the site kit again after you update: run the command from [Install](../getting-started/install.md) with tag `v0.3.0`. Checked on EmDash 1.3.1.
