# What's new in 0.4.1

**Included in Free.** Product Roadmap has no paid version. No new permission. The site kit is unchanged.

- **Guests keep their votes when a site moves to EmDash 1.5.** EmDash 1.5 runs a plugin's install step on the first start after the update for plugins added in the site's config file. On a site that still held 0.3.0 data, that step made a new guest key, so guests could no longer take back votes cast before the update. Install now keeps the 0.3.0 key. Sites that installed from the registry were not affected.
- **Tested on EmDash 1.5.0.** Also tested on EmDash 1.2 and 1.3.

After you update, copy the site kit with tag `v0.4.1` (the files are the same as 0.4.0).
