# What's new in 0.2.2

**Included in Free.** Product Roadmap has no paid version.

- **Guests need a visitor address.** Guests can vote and suggest only when your host tells EmDash the visitor's address: Cloudflare does; any other host needs `trustedProxyHeaders` in the site config. Without it, guests see a sign-in link, members take part as usual, and Admin, Roadmap, Settings says so. See [Install](../getting-started/install.md#guests-and-the-visitor-address).
- **Fairer guest counting.** One guest per IPv4 address or per IPv6 /64. The salted address is cleared from a guest's vote after 30 days; the vote stays.
- **One command for the kit.** `scripts/add-to-site.sh` copies every kit file, your layout only the first time, keeps a backup of a changed wording file, and creates the content types. Ideas shows the exact command for your version until you press **Visitor pages are set up**.
- **One place to set the stage.** The Stage panel on an item has a button per stage, and the editor's own Stage box follows at once. See [Items and stages](../using/items-and-stages.md).
- **Fixes.** Ideas counts a waiting idea once; pages line up with your site's header; buttons stay readable in dark mode.

Copy the site kit again after you update: run the command from [Install](../getting-started/install.md) with tag `v0.2.2`.
