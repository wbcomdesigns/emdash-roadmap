# Merge a duplicate

**Included in Free.** Product Roadmap has no paid version.

When two items or ideas ask for the same thing, merge them. Votes move to the item you keep, one per person, and the old address sends visitors to the kept item.

## Merge two items

1. In admin, open **Roadmap**, then **Ideas**, and open **Merge a duplicate**.
2. In **Merge this item**, pick the one to drop. The list has waiting ideas, marked "(waiting)", and published items.
3. In **Into this item**, pick the one to keep. This list has published items only.
4. Choose **Review merge**.
5. A warning names both items: "Merge (first) into (second)?" It says the first item is unpublished and its votes move to the second.
6. Choose **Merge these two**, then **Merge** in the confirmation box.

You see "Merged. Votes moved to the item you kept."

## What the merge does

- Votes from the dropped item move to the kept one. A person who voted for both is counted once.
- The dropped item is unpublished. Its old address redirects to the kept item.
- If you dropped a waiting idea, it leaves the queue.
- You cannot undo a merge. Check the two names in the warning before you confirm.

## When it refuses

| Message | Why |
| --- | --- |
| Choose both items. | One list is still on "Choose an item" |
| Pick two different items. | You picked the same item twice |
| One of those items is no longer there. | An item was deleted after the page loaded |
| Keep a published item. | The item to keep is not published |
| That idea changed after this page loaded. | Someone else changed the idea. Reload and try again |
