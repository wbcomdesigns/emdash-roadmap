# What's new in 0.1.4

**Included in Free.** Product Roadmap has no paid version.

## For site owners

- **One command creates the content types.** From your site's root folder: `npx emdash seed path/to/emdash-roadmap/site-kit/seed/roadmap-seed.json --no-content`. It never changes your menus. See [Install](../getting-started/install.md).
- **A typo in Stage no longer hides an item.** If an item's stage matches none of your stages, it shows in the first column so you can spot and fix it.
- **New guides.** [Use cases](../getting-started/use-cases.md) and [Use it on blog posts and pages](../getting-started/posts-and-pages.md).

## For visitors

- **A member's vote always shows as theirs.** After a reload, the vote buttons wait until the member's votes are known.
- **The Suggest form is clearer.** The name field says it is needed when you are not signed in, and the cursor goes there if it was left empty.
- **Readable on every light or dark choice.** The board stays readable when a visitor picks your site's light mode on a device set to dark.

Copy the site kit again after you update.
