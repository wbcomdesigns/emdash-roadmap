# What's new in 0.4.0

**Included in Free.** Product Roadmap has no paid version. No new permission.

On Cloudflare Workers, EmDash gives each plugin call 10 requests to the site. 0.4.0 keeps every page, vote, admin screen and hourly run within that, measured on a busy test site. Cloudflare stays marked not supported until it has been checked there.

- **Running vote counts.** Each item keeps its count and a vote moves it in the same step, so the board reads every count at once. A double click or two tabs store one vote.
- **Your 0.3.0 counts are rebuilt.** After the update, Ideas shows **Updating roadmap data for 0.4.0** while counts are rebuilt from the stored votes, a few steps each time Ideas opens and each hour. **Continue** moves it along. Until it ends, a count from before the update can be off by a few.
- **Merging in steps.** A merge starts at once; Ideas shows **Merging ... into ...** while the votes move, 100 at a time, and checks the kept item's count at the end. **Continue** or the hourly task finishes it.
- **Roadmap votes erase in steps.** Take back all my votes repeats by itself until every vote is gone, then says so.
- **Category filter in the page.** The board page filters by category from the one category read it already makes. A category link from before (`?category=Bugs`) still works.
- **Guest vote fix.** On Cloudflare a guest vote on a busy item was refused as "That item is not on the board". A failed read now says "Something went wrong. Try again." and nothing is saved.
- **Content types on Cloudflare.** The kit script runs the seed only on a local SQLite database. Anywhere else it says so, and [Install](../getting-started/install.md#content-types) lists what to create in the admin.

Copy the site kit again after you update: run the command from [Install](../getting-started/install.md) with tag `v0.4.0`. Until you do, the 0.3.0 kit shows every item on a category-filtered board, and Take back all my votes removes 7 votes and then shows an error (press it again to remove the next 7).
