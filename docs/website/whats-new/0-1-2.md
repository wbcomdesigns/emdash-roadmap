# What's new in 0.1.2

**Included in Free.** Product Roadmap has no paid version.

Fixes from a walk through the closed-suggestions, merge and filter screens.

## For site owners

- **Suggestions off now means off.** When you turn off **Allow suggestions**, the board hides **Suggest an idea** and the suggest page shows only the closed message.
- **Merge is clearer.** **Merge a duplicate** starts with "Choose an item", then names both items before you confirm.

## For visitors

- The board filters are labelled **Category** and **Sort**.
- **Suggest an idea** is a main button.
- On a phone, the current stage tab is marked.

## For developers

- Copy the site kit again after updating.
